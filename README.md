# Aether Island

Aether Island is a clean, independent Windows desktop companion implementation.

The new native app is in [AetherIsland/](AetherIsland/). It is written in C# and WPF for .NET 10. It does not build on, link to, or depend on the historical application source retained elsewhere in this repository.

Start with the [Windows app setup guide](AetherIsland/README.md), [architecture](AetherIsland/docs/architecture.md), and [roadmap](AetherIsland/docs/roadmap.md).
